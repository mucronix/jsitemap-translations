# JSitemap Pro Russian Translation

A complete Russian (ru-RU) translation of JSitemap Pro, the `com_jmap` component for Joomla.
It covers the administrator side (control panel, settings, installation messages) and the site
side (the sitemap page).

- **For:** JSitemap Pro 4.31.8
- **Tested with:** JSitemap Pro 4.31.8 on Joomla 6
- **Strings translated:** 2416 of 2416
- **License:** GNU GPL version 2 or later (GPL-2.0-or-later), see `LICENSE`

## Installation

1. Download `jsitemap_ru-RU_4.31.8.zip` from the
   [releases page](https://github.com/mucronix/jsitemap-translations/releases).
2. In the Joomla administrator, go to **System → Install → Extensions**.
3. On the **Upload Package File** tab, select the ZIP file. Joomla installs it immediately.

The package is a Joomla `file` extension. It puts the language files into
`administrator/language/ru-RU/` and `language/ru-RU/`. To remove it, uninstall it from
**System → Manage → Extensions**.

## Repository layout

The files are laid out exactly as in the installation package, so zipping the contents of the
repository (without `README.md`, `LICENSE` and the git files) gives a package with the same files:

```
jsitemap_ru-RU.xml          installation manifest
admin/ru-RU.com_jmap.ini    administrator strings
admin/ru-RU.com_jmap.sys.ini
site/ru-RU.com_jmap.ini     site strings
```
